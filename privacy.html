1. 개인정보처리방침 (Privacy Policy)

1.1 나만 열 수 있는 완전 비공개 보안(Zero-Knowledge) 원칙

HiddenData(이하 '당사' 또는 '본 소프트웨어')는 사용자의 완전한 데이터 프라이버시를 보장하기 위해 설계된 독립형 완전 비공개(Zero-Knowledge) 보안 미디어 금고 솔루션입니다.

본 소프트웨어는 최고 등급 AES-256-GCM 암호화 및 슈퍼컴퓨터로도 뚫을 수 없는 단방향 비밀번호 보호 알고리즘을 사용합니다. 사용자의 마스터 비밀번호, 암호화 키, 평문 파일 및 미디어 원본은 오직 사용자의 로컬 기기 메모리에서만 처리되며, 당사의 원격 서버로 일절 전송되거나 보관되지 않습니다. 개발자를 포함한 그 누구도 사용자의 비밀번호를 열람하거나 임의로 데이터를 복호화할 수 없습니다.

1.2 Google Drive API 사용 및 사용자 데이터 정책 준수 (Limited Use)

HiddenData는 클라우드 금고 백업 및 크로스 플랫폼(PC Chrome 확장 프로그램 ↔ Android 모바일 앱) 데이터 동기화를 위하여 Google Drive REST API를 사용합니다.

당사는 Google API 서비스 사용자 데이터 정책(Google API Services User Data Policy) 및 제한적 사용 요구사항(Limited Use Requirements)을 엄격히 준수합니다:

  • 최소 권한 원칙(Least Privilege): 당사는 오직 'https://www.googleapis.com/auth/drive.file' 권한만을 요청합니다. 이 권한은 HiddenData를 통해 사용자가 직접 생성하거나 업로드한 암호화 파일(.enc), 마스터 설정 파일(.hiddendata_vault_config.json), 그리고 라이선스 동기화 파일(.hiddendata_pro_license.json)에만 한정적으로 접근할 수 있습니다.
  • 타 파일 접근 불가: 당사의 소프트웨어는 사용자의 Google Drive에 저장된 다른 개인 문서, 사진, 폴더 등 HiddenData와 무관한 파일에 대해 일절 접근할 수 없으며 조회 권한조차 보유하지 않습니다.
  • 제3자 비공개 및 AI 학습 금지: Google 사용자 데이터는 제3자 광고주, 데이터 브로커에게 절대 판매되거나 전송되지 않으며, 인공지능(AI) 또는 기계학습(ML) 모델의 학습 목적으로 사용되지 않습니다.

1.3 Chrome 확장 프로그램 권한 명세

PC 크롬 확장 프로그램은 보안 기능 동작을 위해 아래의 필수 권한만을 사용합니다:

  • sidePanel: 브라우징 작업 중 화면 분할을 통해 편리하게 독립형 보안 금고를 열람할 수 있도록 사이드 패널 UI를 제공합니다.
  • storage: 로컬 환경설정(테마, 선택된 금고 경로) 및 비밀번호 오입력 차단을 위한 안전 검증 해시를 브라우저 내부에 안전하게 저장합니다.
  • identity: 사용자의 명시적 요청 시 Google Drive 클라우드 금고 연동 및 Pro 라이선스 동기화를 위한 안전한 OAuth2 로그인 토큰을 발급받습니다.
  • activeTab: 웹서핑 중 사용자가 직접 선택한 이미지나 파일을 암호화 금고로 드래그 앤 드롭하여 가져올 때 안전한 컨텍스트를 지원합니다.

1.4 데이터 보존 및 삭제 정책

당사는 원격 서버에 사용자의 개인정보나 파일 데이터를 일절 저장하지 않으므로, 데이터의 삭제는 전적으로 사용자의 제어 하에 있습니다. 사용자가 로컬 금고 폴더를 삭제하거나, Google Drive에서 HiddenData_Vault 폴더를 삭제하면 해당 데이터는 영구히 파기되며 당사에는 어떠한 잔여 데이터도 남지 않습니다.
