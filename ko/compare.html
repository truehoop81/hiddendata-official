OPEN SOURCE

Cryptomator

일반 문서 및 클라우드 저장소 파일 암호화 도구. 가상 드라이브(FUSE/WebDAV)를 OS 파일 탐색기에 마운트하여 사용.

  • 완전 비공개 AES-256 지원
  • 다양한 클라우드 스토리지 지원
  • 가상 드라이브 마운트 필요

Cloud Vaults (Dropbox/OneDrive)

Dropbox Vault, OneDrive Vault 등 클라우드 제공업체가 제공하는 보관함. 핀 번호/2FA로 잠금 해제.

  • 기존 클라우드 생태계 연동 편리
  • 서버가 암호화 키를 보유 (비공개 불가)
  • 매월 지속적인 클라우드 구독료 발생

Local File Hiders & Lockers

앱스토어의 계산기 사진 숨김앱 등. 대부분 확장자 변경이나 숨김 폴더 이동 방식으로 작동.

  • 간단한 모바일 인터페이스
  • USB/ADB 연결 시 즉시 평문 유출
  • PC 브라우저 연동 지원 불가

03.

심층 분석: HiddenData vs Cryptomator

Cryptomator는 투명한 암호화와 멀티 클라우드 호환성으로 높은 평가를 받는 오픈소스 솔루션입니다. 그러나 Cryptomator와 HiddenData는 설계 목적과 사용 환경이 완전히 다릅니다:

  • 가상 드라이브 vs 브라우저 사이드 패널: Cryptomator는 FUSE/WebDAV 가상 드라이브를 데스크톱에 마운트합니다. 일반 문서에는 유용하지만, 미디어를 열람할 때마다 OS 미디어 플레이어가 실행되며 디스크 캐시와 최근 파일 기록을 남깁니다.
  • 제로 디스크 RAM 스트리밍: HiddenData는 PC Chrome 사이드 패널 내에서 Web Crypto와 TypedArray를 통해 64KB 청크 단위로 메모리에서만 복호화하여 0B 디스크 잔여를 실현합니다.
  • 대용량 동영상 갤러리 탐색: Cryptomator에서 수백 개의 동영상을 탐색하려면 전체 파일을 읽어 썸네일을 생성해야 합니다. HiddenData는 V3 헤더에 암호화된 썸네일이 내장되어 있어 0.005초 만에 갤러리를 엽니다.
어떤 솔루션을 선택해야 할까요?

오피스 문서, 소스 코드 폴더 전체를 가상 드라이브로 암호화하려면 Cryptomator가 적합합니다. 사진, 움짤, 4K 동영상을 PC와 폰에서 흔적 없이 초고속으로 감상하고 안전하게 동기화하려면 HiddenData가 압도적으로 유리합니다.

04.

심층 분석: HiddenData vs 클라우드 기본 금고

OneDrive Personal Vault, Dropbox Vault 등 대기업 클라우드 보관함은 편리해 보이지만 근본적인 한계가 있습니다:

  • 서버 측 키 보관: 클라우드 제공업체가 암호화 키를 관리하므로, AI 학습 데이터 스크래핑이나 법적 요구 시 클라우드 서버에서 파일 내용을 복호화하여 열람할 수 있습니다.
  • 클라이언트 사전 암호화: HiddenData는 데이터가 기기를 떠나기 전에 로컬에서 AES-256-GCM으로 암호화하므로 Google Drive 본사조차 파일 내용을 절대 볼 수 없습니다.
  • 월 구독료 함정: 클라우드 금고는 매월 $9.99~$15의 구독료를 요구합니다. HiddenData는 기존 무료/유료 Google Drive에 연결되며 $8.99 1회 결제로 평생 소장할 수 있습니다.
05.

심층 분석: HiddenData vs 로컬 파일 숨김앱

앱스토어의 수많은 '계산기 비밀 금고' 앱 중 85% 이상은 진정한 암호화를 수행하지 않습니다:

  • 단순 은폐 vs 진정한 암호학: 대다수 앱은 파일 이름 앞에 점(.)을 찍거나 숨김 폴더로 옮길 뿐입니다. 스마트폰을 USB로 PC에 연결하면 모든 사진이 그대로 복사됩니다.
  • 표준 AES-256-GCM & PBKDF2 보안: HiddenData는 NIST 표준 AES-256-GCM과 100,000회 PBKDF2를 적용하여, 플래시 메모리를 물리적으로 복제하더라도 마스터 비밀번호 없이는 브루트포스 해독이 계산상 불가능합니다.
06.

선택 가이드: 내게 맞는 솔루션은?

다음의 경우 HiddenData를 선택하세요:

  • PC에서 개인 사진, 움짤, 4K 동영상을 로컬 디스크 흔적(0B) 없이 열람하고 싶을 때.
  • 웹 서핑이나 업무 창 옆에 간편하게 열 수 있는 Chrome 사이드 패널 뷰어를 원할 때.
  • 스마트폰에서 사진을 숨기고 PC에서 구글 드라이브를 통해 즉시 열람하고 싶을 때.
  • 월 구독료 없이 $8.99 1회 결제로 평생 소장하고 싶을 때.

다음의 경우 타사 솔루션을 고려하세요:

  • Git 저장소나 개발 프로젝트 폴더 전체를 가상 드라이브로 묶고 싶을 때 → Cryptomator 추천.
  • 기업용 싱글 사인온(SSO)과 팀원 간 폴더 공유가 필요할 때 → Boxcryptor / 기업용 클라우드 추천.
  • 아이가 스마트폰 화면을 잠깐 엿보는 것만 막으면 될 때 → 기본 OS 보안 폴더 추천.

비교 관련 자주 묻는 질문 (FAQ)

Q1. HiddenData는 왜 Cryptomator처럼 가상 드라이브를 마운트하지 않나요?
가상 드라이브 방식은 FUSE나 WinFsp 같은 커널 드라이버 설치가 필요하여 관리자 권한이 필수적이고 시스템 충돌 위험이 있습니다. 또한 가상 드라이브에서 열린 미디어는 재생 프로그램에 의해 임시 캐시에 복사됩니다. HiddenData는 브라우저 샌드박스 내에서 MediaSource와 TypedArray로 메모리 직독 스트리밍하므로 커널 드라이버나 임시 파일이 전혀 발생하지 않습니다.
Q2. Google Drive에 암호화된 파일을 올리면 계정이 정지될 수 있나요?
전혀 그렇지 않습니다. Google Drive 이용약관은 사용자가 암호화된 백업 파일을 저장하는 것을 명시적으로 허용합니다. HiddenData는 Google의 공식 REST API 규격과 제한된 drive.file 권한 범위 내에서만 합법적으로 동작합니다.
Q3. 평생 소장(Lifetime) Pro 라이선스는 정말 추가 비용이 없나요?
네, 100% 사실입니다. HiddenData Pro는 $8.99 1회 결제로 영구 소장되며, 숨겨진 월별/연간 구독료가 없습니다. 한 번 구매하면 구글 계정 연동을 통해 PC 크롬 확장 프로그램과 Android 모바일 앱 양쪽 모두에서 영구히 사용하실 수 있습니다.
Q4. 나중에 암호화를 풀고 원본 파일로 되돌릴 수 있나요?
언제든지 가능합니다. 파일 목록에서 원하는 파일이나 전체 파일을 선택한 뒤 '원본으로 내보내기'를 누르면, 즉시 복호화되어 원하는 로컬 저장소 폴더에 원본 사진, GIF, 동영상으로 깨끗하게 저장됩니다.
