01.

개요 및 핵심 보안 보증 (Executive Summary)

HiddenData는 데스크톱 웹 브라우저(Chrome 확장 프로그램 사이드 패널)와 Android 모바일 환경에서 고대역폭 이미지, 애니메이션 GIF, 4K UHD 동영상을 안전하게 스트리밍하기 위해 설계된 엔터프라이즈급 완전 비공개(Zero-Knowledge) 미디어 금고입니다.

기존의 파일 암호화 도구나 모바일 금고 앱은 열람 시 전체 파일을 운영체제 임시 디렉토리(/tmp, AppData/Local/Temp 또는 내부 앱 캐시)에 복호화하여 저장합니다. 반면 HiddenData는 디스크 쓰기를 완전히 제거했습니다. 모든 복호화는 온디맨드 방식으로 시스템 메모리(RAM)에서만 처리되며, 창을 닫는 즉시 제로라이징(Zeroization) 메모리 소거가 실행됩니다.

완전 비공개(Zero-Knowledge) 절대 원칙

앱 개발자, Google Drive 클라우드 서버, 네트워크 중간자 등 그 누구도 사용자의 마스터 비밀번호, 유도된 암호화 키, 평문 미디어 원본에 접근할 수 없습니다. 사용자가 마스터 비밀번호를 분실하면 수학적으로 복구가 불가능하며, 어떠한 에스크로 키나 관리자 백도어도 존재하지 않습니다.

02.

암호학 프리미티브 및 키 파생 규격

모든 암호화 작업은 미국 국립표준기술원(NIST) 권고사항과 최신 인증 암호화(AEAD) 표준을 엄격히 준수합니다.

암호학 파라미터 표준 및 구현 방식 보안 목적 및 근거
대칭키 암호 알고리즘 AES-256-GCM (NoPadding) Galois/Counter Mode를 통해 하드웨어 가속을 활용한 초고속 기밀성과 128비트 무결성 인증(AEAD)을 동시 제공합니다.
암호화 키 길이 256-bit (32 bytes) AES 최고 강도의 256비트 키를 사용하여 양자 컴퓨터의 Grover 알고리즘 공격에도 안전합니다(유효 양자 보안 128비트).
키 파생 함수 (KDF) PBKDF2-HMAC-SHA256 사용자 비밀번호를 256비트 키 암호화 키(KEK)로 확장하여 GPU/ASIC 레인보우 테이블 공격을 방어합니다.
KDF 작업 강도 (반복 횟수) 100,000 iterations 100,000회 반복 연산으로 무차별 대입 공격에 막대한 연산 비용을 강제하면서도 로컬 잠금 해제는 250ms 이내로 완료합니다.
솔트 (Salt) 생성 16-byte CSPRNG 암호학적으로 안전한 난수 생성기(crypto.getRandomValues / SecureRandom)로 파일마다 16바이트 고유 솔트를 생성합니다.
청크 AEAD 논스 (Nonce) 96-bit (Base IV ⊕ Chunk Index) 12바이트 Base IV와 64비트 청크 카운터 XOR 연산을 결합하여 논스 재사용 및 청크 순서 조작 공격을 원천 차단합니다.
즉각 키 검증자 (Key Verifier) 16-byte SHA-256 Digest 대용량 본문 복호화 시도 없이 0.001초 만에 마스터 비밀번호의 일치 여부를 판별합니다.
라이선스 무결성 검증 HMAC-SHA256 (V2 Protocol) 원격 중앙 계정 서버 없이도 Android와 PC 간 Pro 라이선스를 안전하게 검증하는 HMAC-SHA256 전자서명 아키텍처입니다.
추가 인증 데이터 (AAD) 바인딩 공격 방어

공격자가 서로 다른 암호화 파일 간에 청크를 짜깁기하는 공격을 방지하기 위해, 파일 봉투 헤더의 첫 32바이트를 모든 64KB 청크 암호화의 AAD(Additional Authenticated Data)로 바인딩합니다. 청크의 순서나 출처가 조금이라도 위변조되면 GCM 인증 태그 검증이 즉시 실패합니다.

03.

제로 디스크(Zero-Disk) 인메모리 스트리밍 파이프라인

기존의 파일 암호화 도구는 '디스크 복호화' 방식으로 작동합니다. 사용자가 암호화된 동영상을 클릭하면 임시 폴더에 평문 파일을 생성하고 시스템 플레이어로 전달한 뒤, 재생 창이 닫힐 때 삭제를 시도합니다.

이러한 레거시 방식은 심각한 보안 및 프라이버시 취약점을 유발합니다:

  • 디스크 포렌식 잔여 흔적: 파일이 삭제되어도 플래시/하드디스크의 미할당 클러스터에 원본 데이터가 남아 있어 EnCase, FTK 등의 포렌식 도구로 손쉽게 복구됩니다.
  • OS 썸네일 및 활동 로그: Windows Shell이나 macOS Spotlight가 임시 폴더를 즉시 색인하여 암호화되지 않은 썸네일 캐시와 셸백(Shellbag) 기록을 생성합니다.
  • 비정상 종료 시 고아 파일 방치: 앱이 강제 종료되거나 전원이 꺼지면 복호화된 평문 파일이 디스크에 영구적으로 방치됩니다.

HiddenData의 제로 디스크 솔루션: Android 앱과 Chrome 사이드 패널 모두 인메모리 스트리밍 파이프라인을 탑재했습니다:

4K 60fps 대용량 동영상을 재생할 때 HiddenData는 바이트 레인지 요청을 통해 64KB 청크 단위로 가져옵니다. 각 청크는 메모리(RAM)에서 검증 및 복호화되어 브라우저의 MediaSource 버퍼나 Android MediaCodec 파이프라인으로 직접 전달됩니다. 재생을 종료하면 메모리 버퍼는 Arrays.fill(buffer, 0)을 통해 즉시 0으로 덮어씌워져 파기됩니다.

KeySlotManager 및 0.001초 원자적 비밀번호 변경

기존의 암호화 금고는 마스터 비밀번호를 변경하려면 수백 기가바이트의 저장소 전체를 다시 복호화하고 재암호화해야 했습니다. 이는 SSD 수명을 단축시키고 정전 시 데이터 파손 위험을 초래합니다.

HiddenData는 KeySlotManager 봉투 암호화로 이를 해결합니다. 파일 본문은 고유한 256비트 마스터 키(MK)로 암호화되며, 이 MK만이 사용자 비밀번호에서 파생된 키 암호화 키(KEK)로 암호화되어 헤더에 저장됩니다.

원자적 키 교체 성능: 정확히 0.001초

비밀번호를 변경할 때 HiddenData는 수 기가바이트의 본문 데이터는 일절 건드리지 않고, 헤더 내 32바이트 마스터 키 슬롯만 새로운 KEK로 재암호화합니다. 파일당 1밀리초만에 원자적(Atomic)으로 갱신되므로 대용량 금고도 데이터 손상 위험 없이 즉시 완료됩니다.

헤더 내장 V3 썸네일 블록 (0.005초 초고속 미리보기)

수천 개의 암호화 파일이 있는 대형 금고에서도 부드러운 60fps 갤러리 탐색을 제공하기 위해, V3 헤더에는 128x128 크기의 암호화된 WebP 썸네일이 내장되어 있습니다. 전체 파일을 읽을 필요 없이 앞부분 2KB만 직독하여 0.005초 만에 미리보기를 렌더링합니다.

05.

Google Drive 최소 권한 격리 (drive.file 스코프)

클라우드 백업 시 많은 서드파티 앱이 구글 드라이브 전체 권한(.../auth/drive)을 요구하여 사용자의 모든 개인 문서와 사진을 열람할 수 있는 위험을 안깁니다.

권한 유형 OAuth 2.0 스코프 URI 접근 가능 범위 프라이버시 위험 평가
HiddenData 보안 정책 .../auth/drive.file 오직 HiddenData가 직접 생성한 암호화 파일(.enc) 및 설정 파일에만 한정 접근. 기존 개인 드라이브 파일 접근 권한 0%. CASA 보안 심사 완료 / 위험 없음
일반 클라우드 금고 앱 .../auth/drive 사용자의 Google Drive 전체 파일에 대한 무제한 읽기/쓰기/삭제 권한 부여. 치명적인 보안 위협

HiddenData는 최소 권한 원칙(Principle of Least Privilege)을 철저히 준수합니다:

  • 기존 개인 파일 접근 일절 불가: HiddenData 외부에서 생성된 구글 문서, 스프레드시트, 사진 등에 대해 조회 권한조차 보유하지 않습니다.
  • 100% 암호문(Ciphertext) 보관: Google Drive의 HiddenData_Vault 폴더에 저장되는 모든 파일은 로컬에서 암호화된 난수 바이너리 블록입니다.
  • 중간 서버 없는 P2P 클라우드 통신: 사용자 기기와 Google 공식 REST API 엔드포인트 간에 TLS 1.3으로 직접 통신하며 개발사 중간 서버가 없습니다.
06.

크로스 플랫폼 Pro 라이선스 무결성 검증 프로토콜

HiddenData는 중앙 회원가입 데이터베이스를 운영하지 않습니다. Lemon Squeezy를 통해 Pro 라이선스를 구매했을 때, 추적 서버 없이 어떻게 PC와 모바일 간에 정품 인증을 안전하게 동기화할까요?

그 해답은 V2 전자서명 라이선스 봉투(.hiddendata_pro_license.json)입니다:

  • 구매 완료 시 결제 웹훅이 사용자의 구글 이메일과 주문 번호를 결합한 HMAC-SHA256 디지털 서명을 발급합니다.
  • 이 암호화된 라이선스 토큰은 사용자의 개인 Google Drive 금고 폴더에 안전하게 저장됩니다.
  • Android 앱이나 PC Chrome 확장 프로그램이 실행될 때 오프라인에서 암호학적 서명을 즉시 검증하여, 추가 결제 없이 영구적으로 Pro 기능을 활성화합니다.
