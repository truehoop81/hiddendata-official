OUR SOLUTION

HiddenData Studio

メディア専用の100%完全非公開スタジオ。一時ファイル0BでChromeサイドパネルとAndroidから4K/GIFをRAMストリーミング再生。

  • 0B ディスク残余一時ファイル
  • ブラウザネイティブ4K/GIF再生
  • 最小権限 drive.file スコープ
  • $8.99 買い切り永久ライセンス
OPEN SOURCE

Cryptomator

一般文書向けクラウド暗号化の定番オープンソース。仮想ドライブ（FUSE/WebDAV）をOSにマウントして使用。

  • オープンソース AES-256 実装
  • 多様なクラウドストレージに対応
  • 仮想ドライブのマウントが必要
  • ブラウザ内サイドパネル再生に非対応
PROPRIETARY CLOUD

Cloud Vaults (Dropbox/OneDrive)

Dropbox Vault、OneDrive Personal Vault等。クラウド事業者が提供するPIN保護フォルダ。

  • 既存のクラウド機能との連携が容易
  • 事業者が鍵を管理（非公開ではない）
  • 月額のクラウド利用料が必須
MOBILE APP LOCKERS

Local File Hiders & Lockers

アプリストアの電卓型写真隠しアプリ等。多くは拡張子の変更や隠しフォルダ移動のみ。

  • スマホで手軽に使える
  • PCにUSB接続すると平文が即座に流出
  • PCブラウザとの連携機能なし

03.

徹底比較: HiddenData vs Cryptomator

Cryptomatorは透明性の高い暗号化と優れたマルチクラウド対応で知られる優秀なオープンソース製品です。しかし、HiddenDataとは想定されるユースケースが根本的に異なります：

  • 仮想ドライブ vs ブラウザサイドパネル：CryptomatorはFUSE/WebDAV仮想ドライブをOSにマウントします。文書管理には最適ですが、メディアを開くたびにOS標準プレイヤーが起動し、キャッシュや履歴が残ります。
  • ゼロディスクRAMストリーミング：HiddenDataはChromeサイドパネル内で動作し、Web CryptoとTypedArrayにより64KB単位でメモリ上のみで復号するため、ディスク痕跡が0Bです。
  • 大容量動画ギャラリーの閲覧：Cryptomatorで多数の動画を閲覧するには全体をスキャンする必要がありますが、HiddenDataはヘッダー内蔵サムネイルにより0.005秒で表示されます。
どちらを選ぶべきか？

Office文書やソースコードフォルダ全体を仮想ドライブとして暗号化したい場合はCryptomatorが最適です。写真、GIF、4K動画をPCとスマホで痕跡を残さず快適に鑑賞・同期したい場合はHiddenDataが圧倒的に優れています。

04.

徹底比較: HiddenData vs クラウド標準金庫

OneDriveやDropboxなどのクラウド保管庫は手軽に見えますが、構造的な制約があります：

  • サーバー側での鍵管理：事業者が暗号鍵を管理しているため、AI学習用のデータ収集や法的手続きに応じる形でファイル内容が復号される可能性があります。
  • 端末側での事前暗号化：HiddenDataは送信前に端末上でAES-256-GCM暗号化を行うため、Googleのサーバー上でも完全な暗号文としてのみ存在します。
  • 月額費用の負担：クラウド金庫は月額$9.99〜$15の契約が必要です。HiddenDataはお手持ちのGoogle Driveに接続し、$8.99の1回払いで永久に使用できます。
05.

徹底比較: HiddenData vs スマホ写真隠しアプリ

アプリストアの電卓型写真隠しアプリの85%以上は、実際には暗号化を行っていません：

  • 単なる不可視化 vs 本物の暗号学：ファイル名の先頭にドットを付けたり隠しフォルダに移すだけの場合、スマホをUSBでPCに接続すればPINなしですべての写真がコピー可能です。
  • 標準AES-256-GCM & PBKDF2の安全性：HiddenDataはNIST標準のAES-256-GCMと10万回のPBKDF2を採用しており、ストレージを物理的に複製されてもパスワードがなければ総当たり攻撃による復号は計算上不可能です。
06.

選択ガイド: あなたに最適なツールは？

以下のような場合はHiddenDataをおすすめします:

  • PCで個人的な写真や4K動画をディスク痕跡（0B）なしで閲覧したいとき。
  • 作業画面の横に手軽に開けるChromeサイドパネル金庫を使いたいとき。
  • スマホで保存したメディアをPCのGoogleドライブ経由ですぐに見たいとき。
  • 月額料金なしの$8.99買い切り永久ライセンスを好むとき。

以下のような場合は他の選択肢を検討してください:

  • Gitリポジトリや開発フォルダ全体を暗号化したい場合 → Cryptomatorを推奨。
  • 社内SSO連携やチーム間でのフォルダ共有が必要な場合 → Boxcryptor等の法人クラウドを推奨。
  • 家族にスマホ画面をチラ見されるのを防ぐだけでよい場合 → OS標準のセキュリティフォルダを推奨。

07.

比較に関するよくある質問 (FAQ)

Q1. なぜHiddenDataはCryptomatorのように仮想ドライブを使用しないのですか？
仮想ドライブにはFUSE等のカーネルドライバが必要で、管理者権限が必須となり不具合の原因になることがあります。また、仮想ドライブから開かれたメディアはプレイヤーの一時キャッシュに保存されます。HiddenDataはブラウザサンドボックス内でMediaSourceとTypedArrayを用いてメモリ内のみで直接ストリーミングするため、カーネルドライバも一時ファイルも不要です。
Q2. Google Driveに暗号化ファイルを保存するとアカウントが停止されますか？
いいえ、停止されることはありません。Google Driveの利用規約では暗号化されたバックアップファイルの保管が認められています。HiddenDataはGoogle公式のREST API仕様と制限されたdrive.file権限の範囲内で合法的に動作します。
Q3. 永久ライセンス（Lifetime）は本当に追加料金が不要ですか？
はい、追加料金は一切ありません。HiddenData Proは$8.99の1回払いのみで、月額・年額のサブスクリプションはありません。Googleアカウントの連携により、PCとAndroidの双方で永久にご利用いただけます。
Q4. 後から暗号化を解除して元のファイルに戻すことはできますか？
いつでも可能です。ファイル一覧から対象を選択して「元のファイルとしてエクスポート」を実行すれば、選択したローカルフォルダに元の写真、GIF、動画として綺麗に復号保存されます。
