1. Política de Privacidade (Privacy Policy)

1.1 Princípios de Segurança e Total Privacidade (Zero-Knowledge)

O HiddenData ('o Software') é uma solução de cofre de mídia criptografado projetada com arquitetura Zero-Knowledge para assegurar privacidade irrestrita.

O Software emprega criptografia autenticada padrão AES-256-GCM e derivação de chave PBKDF2-HMAC-SHA256. Sua senha mestra, chaves e arquivos originais são processados exclusivamente na memória RAM local e nunca são enviados aos nossos servidores. Como uma arquitetura de conhecimento zero (Zero-Knowledge), não existem portas dos fundos e apenas o detentor das credenciais mestras pode descriptografar os dados.

1.2 Uso da Google Drive API & Conformidade com Requisitos de Uso Limitado

O HiddenData utiliza a API do Google Drive exclusivamente para backup na nuvem e sincronização entre a extensão para PC e o aplicativo móvel Android.

Cumprimos rigorosamente a Política de Dados de Usuário dos Serviços de API do Google e as exigências de Uso Limitado (Limited Use):

  • Princípio do menor privilégio: Solicitamos apenas o escopo 'https://www.googleapis.com/auth/drive.file', restrito aos arquivos .enc e de configuração criados diretamente pelo HiddenData.
  • Sem acesso a outros arquivos: O Software não possui permissão para ler ou modificar qualquer outro documento ou foto do seu Google Drive.
  • Sem venda a terceiros ou treinamento de IA: Dados do Google nunca são vendidos ou compartilhados com corretores de anúncios, nem usados para treinar Inteligência Artificial (IA).

1.3 Permissões da Extensão Chrome

A extensão para PC Chrome solicita apenas permissões estritamente necessárias:

  • sidePanel: Fornece a interface do painel lateral para acessar o cofre enquanto navega.
  • storage: Armazena com segurança preferências locais e o hash de verificação de segurança.
  • identity: Permite autenticação OAuth2 segura para conexão com o Google Drive e sincronização Pro.
  • activeTab: Permite arrastar e soltar imagens web com segurança diretamente para o cofre criptografado.

1.4 Retenção e Exclusão de Dados

Como não guardamos dados de usuários em servidores remotos, a exclusão dos dados fica 100% em suas mãos. Ao apagar sua pasta local ou a pasta HiddenData_Vault no Google Drive, seus dados são permanentemente destruídos.
