隱私權政策、服務條款與退款政策

最後更新日期：2026年3月1日 | 生效日期：2026年3月1日

1. 隱私權政策 (Privacy Policy)

1.1 100% 完全隱私 (Zero-Knowledge) 安全架構原則

HiddenData（以下簡稱「本軟體」或「我們」）是一套旨在保證絕對資料隱私的獨立完全私密媒體金庫解決方案。

本軟體採用標準 AES-256-GCM 認證加密與 PBKDF2-HMAC-SHA256 金鑰衍生函數。您的主密碼、加密密鑰與原始媒體僅於您的本機記憶體 (RAM) 中運算處理，絕不會上傳或儲存於我們的伺服器。客戶端零知識 (Zero-Knowledge) 架構確保無任何後門金鑰，僅有掌握主憑證的使用者本人能解密資料。

1.2 Google Drive API 使用與有限使用規範遵循 (Limited Use)

HiddenData 僅使用 Google Drive REST API 進行雲端金庫備份以及 PC Chrome 擴充功能與 Android 行動版之間的跨裝置資料同步。

我們嚴格遵守 Google API 服務使用者資料政策 (Google API Services User Data Policy) 及有限使用條款 (Limited Use Requirements)：

  • 最小權限原則：我們僅申請 'https://www.googleapis.com/auth/drive.file' 權限。此權限僅能存取由 HiddenData 直接建立的加密檔案 (.enc)、主設定檔與授權同步檔。
  • 無法讀取其他檔案：本軟體完全無法存取或窺探您 Google Drive 中儲存的其他私人文件、相片或資料夾。
  • 禁止第三方分享與 AI 訓練：Google 使用者資料絕不販售或提供給第三方廣告商，亦絕不用於訓練人工智慧 (AI) 或機器學習模型。

1.3 Chrome 擴充功能權限說明

PC Chrome 擴充功能僅要求確保金庫正常運作之必要權限：

  • sidePanel：提供側邊面板介面，讓您在瀏覽網頁時隨時取用金庫。
  • storage：於本機瀏覽器內安全儲存設定偏好與防範錯誤密碼嘗試的安全驗證雜湊值。
  • identity：於您明確要求時取得安全的 OAuth2 憑證以連動 Google Drive 並同步 Pro 授權。
  • activeTab：協助您安全地將網路圖片或檔案拖放匯入至加密金庫中。

1.4 資料保留與刪除政策

由於我們不在遠端伺服器保留任何使用者資料，資料刪除完全由您掌控。刪除本機金庫或 Google Drive 上的金庫資料夾，即可永久銷毀資料。
